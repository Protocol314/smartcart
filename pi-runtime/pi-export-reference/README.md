# 제공받은 Pi 소스 기준본

다른 사용자가 제공한 `SmartCart_export_20261119_113516.zip`에서 소스 허용 목록으로 추출한 보존본이다. 장치별 설정·AT 백업·인증서·키·로그·측정 기록·기존 ROS 빌드는 포함하지 않는다. 이 폴더와 현재 Pi에서 실행 중인 파일의 해시는 비교하지 않았으므로 두 버전의 일치를 확정할 수 없다.

원본 `manual.sh`와 `drive.py`는 실제 GPIO를 열 수 있는 기존 수동 구동 코드다. LiDAR·UWB 이상 시 구동 잠금과 2초 응답 감시가 연결되었다고 확인된 버전이 아니며, 실제 주행 안전 검수도 완료되지 않았다. 따라서 이 보존본을 자동 설치하거나 Pi에 덮어쓰지 않는다. 센서·극성·비상정지와 현장 조건은 운영 런북 및 HANDOFF를 확인한다.

상위 `pi-runtime/` 루트는 이후 수정한 MOCK 전용 Pi 실행 **후보**다. 이 보존본과 후보는 자동 동기화되지 않는다. 원본 ZIP과 장치 백업은 로컬에 별도 보존한다.
