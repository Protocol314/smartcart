가정: 좌우 간격 0.45m, BU04 중앙은 LiDAR보다 0.10m 앞, 방향 동일, UWB 거리는 수평 거리. 표시 X는 원본 부호 반전 후 1.25m를 뺀 시험값입니다. 높이·거리 모델·장착은 검수 전입니다.

단일 가정 위치는 원시 관측으로 표시합니다. 좌우 평균점은 화면 전용 중위값·평활 필터로 조금 늦게 표시됩니다.

좌우 차이가 0.60m를 넘으면 평균을 불일치 십자로만 표시하고 군집과 연관하지 않습니다. 0.60m에 군집 반경을 더한 거리 안의 인접 군집은 시간 정합 전 화면 비교용 후보이며 사람 판별이나 추종·구동 명령이 아닙니다.
