# 운영 런북 관리

운영 본문은 [Markdown](<Smart-Cart Raspberry Pi 4 기본 운영 런북.md>), 열람·코드 복사본은 [HTML](<Smart-Cart Raspberry Pi 4 기본 운영 런북.html>)이다. 본문은 MD 한 곳에서 수정하고 같은 이름의 HTML을 생성한다.

저장소 루트에서:

```powershell
python -X utf8 runbook/build_runbook.py
python -X utf8 runbook/build_runbook.py --check
python -X utf8 runbook/build_runbook.py --self-test
```

외부 패키지·CDN 없이 생성한다. `--check`는 MD의 해시와 생성된 전체 HTML 일치를 검사한다. 헤더·코드·표·링크는 허용한 문법만 렌더링하며 원시 HTML은 이스케이프한다. 복사 버튼은 `textContent`만 클립보드에 쓰고 명령을 실행하지 않는다.

## 2026-11-17 시스템 ON 안내

- 왼쪽 BU04의 수평거리 가정 시험, 별도 LAN 가상 시연 중계기 시작·종료와 센서·가상 RPM의 의미를 현재 Pi 상태에 맞춰 추가했다. 최신 스마트폰 확인은 사용자 보고이며 실제 모터 구동은 확인하지 않았다.
- 현행 모터 배선과 다른 레거시 수동 시험 명령을 현재 배선에서 실행하지 않도록 표시했다. 오래된 배포물 10개는 해시 대조 후 `build/release-archive-20261117/`로 이동했다.
- 맨 앞에 PC의 SSH 접속, Pi의 센싱 시작, PC의 별도 웹 터널을 세 복사 블록으로 배치했다. 예시 IP는 사용자 확인값이며 바뀌면 두 SSH 명령 모두 갱신한다.
- Pi 서버와 PC 터널의 역할·두 창 유지·종료와 기존 `ssh -L` 터널 중복을 구분했다. 센싱 명령이 모터를 구동하지 않는다는 설명을 유지했다.

## 2026-11-05 실행 명령 안내

- 두 실행 명령을 HTML 본문 맨 앞에 다시 배치했다. 모터 시험 전체 Python 원본을 Pi Bash의 덮어쓰기 방지 파일 생성 블록에 포함했다. 생성 자체는 GPIO를 구동하지 않는다.
- 생성 블록의 Python 본문은 기존 원본과 바이트 단위로 일치하며, 갱신된 코드 블록 56개는 MD·HTML 간 원문이 일치한다.
- 1.1절에 실측 센싱 한 명령과 SSH 터널·브라우저 실행 방법을 앞쪽에 배치했다. 기존 11.1절도 유지한다.
- 1.2절과 2.4절에 독립 모터 수동 시험 명령, 시험 전 확인, Pi 파일 검증과 누락 시 PC 전송 절차를 추가했다. 실제 회전 방향 검수와 센싱 연동 구동은 별도다.
- MD·HTML 동기화와 생성기 자체 검사 8개, 코드 블록 53개 원문 일치를 확인했다. 새 Bash 블록 5개와 PowerShell 블록 1개는 실행 없이 구문만 검사했다. Pi 접속·패키지 설치·GPIO·모터 시험은 수행하지 않았다.

## 2026-10-27 검증

- 생성기 자체 검사 8개 통과, HTML·MD 동기화 통과.
- 최초 갱신 시 코드 블록 43개가 HTML의 복사 원문과 일치했다. 실측 시작 안내 추가 후 HTML을 다시 생성하고 동기화를 확인했다.
- 좌우 BU04 표시 안내를 추가한 뒤 MD·HTML 동기화와 생성기 8개 검사를 다시 통과했다. Pi에 표시 업데이트·재시작 수정을 반영하고 실제 브라우저의 좌우 패널과 LiDAR 3m 설정 보존을 확인했다.
- 후속 문서 갱신에서 현재 Pi의 실측 시작을 기본 진입점으로 정리하고 6.3절에 기반 0.3.1 이후 파일 전송·검증·반영을 추가했다. 현재 Pi에는 이미 반영돼 있다. 기술 백서와 README는 같은 시작 명령·실측 범위·미검증 한계를 따른다.
- 해당 갱신 뒤 README·기술 문서·런북 20개에서 링크 128개·Bash 83개·PowerShell 34개·내장 Python 3개의 구문을 확인했다. 명령은 구문만 검사했고 새 SSH·APT·전원 조작은 실행하지 않았다.
- 최초 갱신의 Bash 36개, PowerShell 6개, 내장 Python 2개의 구문 검사를 통과했다. 후속 `start-live.sh`는 Bash 구문과 Linux 가상 환경 적용·실측 인수·준비 부족 거부를 추가 검사했다. 이 문서 명령의 APT·SSH·실물 센서 실행은 해당 검사에 포함하지 않는다.
- USB 배정 블록은 가상 세 장치로 정상 저장·식별 불일치 거부·실물 대조 미확인 거부를 검사. 장착·거리 검수 플래그와 변경 전 백업 보존 확인.
- 실제 브라우저의 목차 이동·43개 복사 버튼·클립보드 원문 일치·JavaScript 오류 없음 확인.
- 데스크톱·모바일 390px 설정에서 전체 문서의 가로 넘침 없음 확인. 표와 코드는 개별 스크롤을 사용.
- 검수 도구는 `file:` 탐색을 허용하지 않아 직접 파일 열기는 실행하지 않음. 루프백 HTTP 미리보기와 외부 자산 없는 독립 HTML 구조를 검사.

증빙·원본 보존본은 Git 제외 경로 `build/verification/runbook-20261027/`에 있다. 기존 펌웨어·센싱 런타임·하드웨어 설정은 이번 문서 작업에서 변경하지 않았다.

배포 버전·해시, 실제 장치 식별값, 세 LiDAR 프레임, source 순서, CLI 인수가 바뀌면 본문과 코드 블록도 함께 대조한다. 로컬 실제 식별값·로그를 문서 예제로 복사하지 않는다.
