# 전방·장착 위치 보정

## 좌표 계약

ROS LaserScan 정의에서 `angle_min + i × angle_increment`는 센서 프레임의 i번째 각도입니다. 0 rad는 +X 전방, +Z 방향에서 본 양의 각도는 반시계 방향입니다. 이 프로젝트에서는 카트 +X를 위쪽, 카트 +Y를 화면 왼쪽으로 표시합니다. 근거는 [공식 LaserScan 정의](https://github.com/ros2/common_interfaces/blob/humble/sensor_msgs/msg/LaserScan.msg)입니다.

사용자가 지정한 L카의 앞쪽을 카트 +X로 정합니다. 앞쪽 좌우 구동륜으로 방향을 바꾸는 전륜 차동구동 도식이며, 현재 차체 기호는 실치수 CAD가 아닙니다.

고정 장착 변환은 다음과 같습니다.

```text
θi = angle_min + i · angle_increment
Xcart = offsetX + ri · cos(θi + yaw)
Ycart = offsetY + ri · sin(θi + yaw)

화면 X = 중심 X − Ycart · pixels_per_meter
화면 Y = 중심 Y − Xcart · pixels_per_meter
```

`offsetX`는 카트 중심에서 LiDAR 원점까지의 전방 이동량, `offsetY`는 왼쪽 이동량입니다. 단위는 m입니다. yaw는 LiDAR +X를 카트 프레임에서 바라본 회전각이며 양수는 왼쪽/반시계 방향입니다.

**초기 0°, 0 m, 0 m는 검증된 실제 장착값이 아닙니다.** 센서가 카트 중심과 일치한다고 둔 임시 가정입니다. 이 값이 맞지 않으면 방향과 중심 기준 거리도 맞지 않습니다. 서버는 TF를 자동 조회하지 않습니다.

## 실제 보정 순서

1. 구동 모터 전원을 분리하거나 구동륜이 움직이지 않는 조건에서 카트를 고정합니다. 이 프로그램의 ‘화면 정지’는 모터 정지가 아닙니다.
2. 라이다 스캔 평면과 같은 높이에 판지·상자 같은 표적을 놓습니다. 카트의 실제 전방에 1 m 정도 떨어뜨려, 주변 물체와 구분되게 합니다. 여기서 1 m는 시험용 예시이지 교정 표준이 아닙니다.
3. 표적의 표시 방위를 확인합니다. 표적이 화면 왼쪽 +90°에 보인다면 yaw에 −90°를 더하는 방식으로 보정합니다. 반대로 오른쪽에 보인다면 +90° 방향을 검토합니다. 뒤쪽이면 약 180° 차이를 확인합니다.
4. 하단 ‘설정 → 장착 보정’에 yaw를 입력하고 적용합니다. LiDAR의 실제 장착 X/Y도 측정해 입력합니다. 전방으로 20 cm에 장착했다면 `offsetX=0.20`입니다.
5. 표적을 좌측·우측에도 옮겨 좌우가 거울상으로 뒤집히지 않았는지 확인합니다. 한 개의 전방 표적만으로는 반사/좌우 반전 오류를 완전히 판별할 수 없습니다.
6. 1 m·2 m 등의 알려진 위치에서 표시와 실측을 대조합니다. 원점과 측정 기준을 통일하고, 오차를 실험 기록에 남깁니다.

이 UI는 회전·평행이동만 보정합니다. 드라이버의 각도 정의가 잘못되거나 라이다가 수평이 아니면 별도로 원인을 수정해야 합니다. 누락된 각도를 채우거나 잘못된 거리값을 일정 배율로 늘려 정상처럼 보이게 하지 않습니다.

## 방향별 영역

| 영역 | 카트 기준 각도 | 기준 |
|---|---|---|
| 전방 | −45° 이상, +45° 미만 | 카트 +X |
| 좌측 | +45° 이상, +135° 미만 | 카트 +Y |
| 우측 | −135° 이상, −45° 미만 | 카트 −Y |
| 후방 | 그 밖의 각도 | 카트 −X |

최단 반사 거리는 **유효하고 표시 반경 안에 있는 점의 카트 중심까지 거리**입니다. 차체 외곽 여유거리, 정지거리, 충돌 가능성, 안전 주행 여부와 같지 않습니다. 장착 오프셋이 있으면 센서 자체 거리 `ri`와 카트 중심 거리는 다릅니다. 점을 클릭하면 카트 중심 거리와 X/Y를 확인할 수 있고, 원본 센서 거리 `ri`는 스캔 JSON에 보존됩니다.

미반환·센서 범위 밖·배열 생략 등으로 유효점이 없는 영역은 `— / 미확인`입니다. 5 m 공간이 비어 있다고 단정하지 않습니다. 5 cm 부근 실제 반사가 보이는 원인은 첨부 값만으로 확정할 수 없습니다. 장착물·카트 프레임·가림 등을 실물에서 확인해야 합니다.

## 최신 스캔만 표시

v1.0.1에서는 프레임 잔상 기능을 제거했습니다. 윤곽선도 단일 스캔 안에서만 생성합니다. 주행 중 이전 프레임을 누적하거나 카트 이동을 보정하지 않습니다.
