# 실측점 기반 윤곽선

## 표시하는 것

각도별 LaserScan 거리값을 모두 유지하여 **작은 측정점 + 얇은 인접점 연결선**으로 표시합니다. 벽은 그 벽에 반사된 여러 빔의 도트 라인으로, 곡면은 반사된 구간의 곡선 형태로 드러납니다. 물체를 대표 점 하나로 축약하거나 `OBJECTS=5`와 같은 추정 개수를 표시하지 않습니다. `RETURNS`는 화면 안의 유효 측정점 수입니다.

선은 두 실측점 사이의 가독성 보조 가이드이지, 그 사이에 추가 측정이 있다는 뜻이 아닙니다. 정확한 물체 분리·종류 판단·표면 복원은 수행하지 않습니다. 한 개의 빔만 돌아오면 그대로 한 점이며 윤곽을 만들어 낼 수 없습니다.

## 좌표와 유효성

```text
θ_i = angle_min + i × angle_increment
X_i = offsetX + r_i × cos(θ_i + yaw)
Y_i = offsetY + r_i × sin(θ_i + yaw)
d_i = hypot(X_i, Y_i)
```

ROS의 +X는 전방, +Y는 좌측입니다. 화면에서는 0°가 위쪽, +90°가 왼쪽, −90°가 오른쪽입니다. 첫 번째 참고 이미지의 시계방향 방위 숫자를 그대로 복사하지 않고 ROS 좌표를 유지했습니다. `yaw=0`·오프셋 0은 실제 장착 측정값이 아닌 초기 가정입니다.

Inf/NaN/null, 센서 최소거리 미만·최대거리 초과는 그리지 않습니다. 카트 중심 변환 후 표시 반경 밖의 점도 그리지 않습니다. **제거된 점의 원래 배열 인덱스는 유지**하므로 인접 관계를 새로 만들지 않습니다. 원본 유한 값은 JSON에서 제거하거나 수정하지 않습니다.

## 연결 조건

`web/js/core.js → buildContours()`에서 다음 조건을 모두 만족할 때만 i번째와 i+1번째 점을 연결합니다.

```text
인덱스: b.index == a.index + 1
각도 간격: abs(angle_increment) <= 2°
빔 간격 추정: s = 2 × min(r_a, r_b) × sin(abs(angle_increment) / 2)
연결 허용 거리: gate = min(maxGap, 0.035 + 3 × s)
점 간 실제 거리: hypot(X_b − X_a, Y_b − Y_a) <= gate
```

`maxGap` 기본값은 0.20 m이고 0.02–0.50 m에서 설정합니다. 노이즈 여유 0.035 m와 간격 배율 3은 시각화용 설계 선택입니다. 점 간 거리가 매우 가까워도 원래 인덱스가 연속하지 않으면 연결하지 않습니다. 서로 다른 스캔, 잘린 배열의 끝과 시작, 360° 스캔의 마지막과 첫 번째를 자동으로 연결하지 않습니다.

이 방식은 [jump-distance 분할 원리](https://github.com/ajtudela/laser_segmentation)를 참고한 독립 구현입니다. 특정 물체 인식 알고리즘의 성능을 보장하지 않습니다. 매우 비스듬한 면은 끊겨 보일 수 있고, 서로 다른 물체의 인접 반사가 충분히 가까우면 하나의 구간으로 연결될 수도 있습니다. 기본 연결 상한을 올리면 잘못 연결될 가능성도 커집니다.

## 색과 렌더링

기본값은 카트 중심 거리 `d_i` 기준 빨강 `<1 m`, 노랑 `1≤d<3 m`, 초록 `d≥3 m`입니다. 두 경계는 설정에서 바꿀 수 있습니다. 화면 확대에 따라 임계값을 자동으로 늘리거나 줄이지 않습니다. 얇은 가이드 선도 거리 경계를 통과하는 지점에서 색상을 분할합니다.

계산 복잡도는 스캔당 O(N)입니다. 모든 표시점에 대해 한 번 좌표를 계산하고 연속점만 검사합니다. 원거리 점을 삭제하거나 대표 점으로 줄여 프레임 속도를 얻는 방식은 아닙니다. 세 색상의 경로를 묶어 한 번씩 렌더링합니다. 격자·실측점·회전선을 별도 Canvas로 분리하므로 회전선이 움직일 때 좌표 변환과 윤곽 계산을 반복하지 않습니다.

회전선은 흰색으로 따로 표시합니다. 색상은 반사점·윤곽에만 사용하며 안전거리·제동거리 기준을 뜻하지 않습니다. 잔상, 과거 스캔 누적, 면 채움, 보간한 가짜 센서점, 3D 높이 생성은 없습니다.

## 첨부 자료의 한계

첨부 스캔은 128/720개 위치의 부분 배열이며 유효 거리값은 56개입니다. 누락된 각도에서 벽이나 사람을 복원하지 않습니다. `SOURCE → 첨부 스캔`은 근접 반사를 0.25 m로 확대하고 `PARTIAL`을 표시합니다. 시연용 방과 원형/직선 윤곽은 `합성 데모`에서만 생성합니다.

두 번째 참고 이미지의 높이별 다층 3D 점군은 이 2D 수평 스캔에 추가하지 않았습니다. 여기서 구현한 것은 최신 2D 단면의 반사 윤곽입니다.
