# 변경 내역

## 2026-10-27 · D5 통합 실측과 한 명령 시작

- 기반 배포 0.3.1 + 후속 파일로 Pi4 Ubuntu 22.04 ARM64·Humble 설치·빌드·LiDAR 및 좌우 BU04 실제 동시 수신·웹 표시 확인.
- `start-live.sh`는 환경 source·고정 로컬 설정·USB 대조·관리 드라이버·좌우 수집·추적/GUI를 한 명령으로 시작. `start-cart.sh/.bat`의 기본 합성 재생은 유지.
- Pi 내장 UART 링크 열거 충돌 수정과 물리 역할 확인·백업 후 배정하는 `prepare-live.py` 추가.
- 실제 dual/status와 연동한 좌우 거리·각도·유효/ID·경과 패널, 독립 SSE 최대 10Hz와 무효·단절·만료 시 과거 값 제거.
- 종료 직후 Linux TCP TIME_WAIT를 점유로 오판하던 시작 검사 수정. 실제 리스너와 실측 중복 잠금·소유 자식 정리 유지.
- 현행 README·운영 런북·기술 백서와 실측/합성 검증 기록 정리. 기존 0.3.1 ZIP과 원본 v1.0.1은 보존.
- 모터 출력·AT·펌웨어·장착 보정 변경 없음. 동시 UWB 무효 측정과 실제 위치 정확도는 후속 검수.

## 1.0.1

- 검정 배경·흰색 UI로 재구성. 레이더/STATUS/SECTOR DISTANCE만 기본 화면에 남김.
- 유효 실측점을 모두 유지하는 도트 라인 및 보수적 인접점 윤곽 추가. 결측·거리 점프·화면 밖·프레임 사이 자동 연결 없음.
- 기본 거리 색상을 빨강 <1 m / 노랑 1–3 m / 초록 ≥3 m로 변경. 사용자 조절 가능. 안전거리 판정은 아님.
- `RETURNS`는 표시점 수. 물체 추정 개수·더미 제어·UWB 표시 제거.
- 상세 보정·진단·내보내기는 설정 창으로 이동. PNG는 레이어를 병합해 출처와 함께 저장.
- 3중 Canvas, 정적 격자 캐시, 스캔 단위 경로 생성, 회전선 최대 30 FPS, DPR 및 버퍼 크기 상한 적용.
- 프레임 잔상 기능 제거. 최신 1개 스캔만 표시.
- 모바일/태블릿 반응형. reduced-motion에서는 회전선만 생략.
- 첨부 부분 스캔은 자동 0.25 m 확대. 데모는 명시적으로 선택한 경우만 사용.
- 기존 ROS 구독·1/2 Hz SSE·CLI·기록/재생 API는 유지. 서버 버전 갱신.
- 이전 대용량 미리보기 이미지는 패키지에서 제외. 외부 CDN/프레임워크/웹폰트 의존성 없음.
