# 이전 UWB 추종 코드 레거시 자료

닫힌 PR #1 브랜치에 있던 Python 코드 3개를 원문 그대로 보존했다. Pi에서 나중에 추출한 실차 서버 코드와 다른 이전 버전이며, 현재 실행 경로에 연결되지 않는다.

이 자료에는 필요한 `lidar_guard.py`, `certificates.py`, 웹 화면이 없고, 서버는 기본적으로 실제 GPIO를 선택한다. 센서 이상 뒤 무장 유지·복구 동작도 별도 검토가 필요하다. 실차 적용이나 실행에 사용하지 않는다.

기존 브랜치의 `follow_config.json`은 장치 설정이므로 GitHub main에 포함하지 않았다. 해당 설정을 포함한 원본 4개 파일은 사용자 PC의 `SmartCart_latest_PR/`에 보존돼 있다. 이는 설정 유효성이나 실제 장착의 확인을 뜻하지 않는다.
