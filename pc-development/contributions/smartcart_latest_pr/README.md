# 전달받은 UWB 추종 코드 검토본

다른 사용자가 전달한 `SmartCart_latest_PR/`의 네 파일을 원문 그대로 보존했다. 기존 Pi 코드나 가상 주행에 연결하지 않은 검토용 코드이며, 병합·실행·배포된 버전이 아니다.

현재 제공된 파일만으로는 `lidar_guard.py`, `certificates.py`, `web/`이 없어 서버를 완성하거나 실행할 수 없다. 기존 Pi의 `drive.py`, 로그인 코드와 특정 설치 경로에도 의존한다. 이 폴더는 `pc-development/virtual-lab-18084/`와 별개다.

전달된 설정은 `lidar_enabled: false`이고 서버는 기본적으로 실제 GPIO 백엔드를 선택한다. 센서 이상 뒤 출력 일시정지와 복구 동작을 포함하므로 현재 프로젝트의 센서 오류 잠금·명시적 재활성화 요구와 대조가 필요하다. 장애물 자동 우회는 구현되어 있지 않다. 거리·각도 모델, 전진 극성, 비상정지 피드백과 실물 정지 조건도 검증되지 않았다. 실기에서 실행하지 않는다.

추가 파일 확보와 함께 기존 안전 잠금을 통합하고 MOCK 가상 시험, 장치·네트워크·ROS 검증 및 독립적인 실물 검수를 거쳐야 한다. 이 보존은 실제 구동 승인이나 안전성 검증이 아니다.
